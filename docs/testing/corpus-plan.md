# Test corpus plan

Fixtures Stage 1 needs, where each comes from, and under what license (M0 deliverable "test corpus
plan", spec §28 M0; sources §25.3, §27.4; plan §5.4). Status as of S1-0: nothing below exists yet.

## Storage policy

- **In the repository:** small fixtures only, each under 1 MiB: synthetic images, native fixtures per
  schema minor, the malformed corpus, fuzz seeds, goldens. Goldens live in `tests/fixtures/golden/`
  with a README stating how each was produced; changing one needs a commit message saying why
  (spec §27.3).
- **Outside the repository:** large or third-party files go in `~/.local/share/archmage-dev/corpus/`,
  standing in for the artifact store of spec §27.4 until one exists. Each file is recorded in the
  register below with its SHA-256, size, source, license and the command that produced it.
- Generated fixtures come from checked-in scripts (`scripts/make_fixtures.py` from S1-6, or the test
  code itself) with fixed seeds, so the corpus can be rebuilt and checked by hash.
- A third-party file is used only after its license is recorded here and in
  `docs/dependencies/manifest.yaml` (spec §5.3).
